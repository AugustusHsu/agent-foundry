1. **機械層不要求**。`handbook-stamp` 的判準是「戳記之後每一顆改 protocol 的 commit 都要有

2. **推戳記是一句宣稱，本輪撐不起那句話**。戳記的語意是「這一章我逐章對照過 protocol」。
